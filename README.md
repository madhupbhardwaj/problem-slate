# problem-slate website

Static GitHub Pages website for problem-slate.

## Publish with GitHub Pages

1. Create a new GitHub repository.
2. Upload everything in this folder to the repository root. `index.html` must remain at the top level.
3. Open **Settings → Pages** in the repository.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose your main branch and the **/(root)** folder, then click **Save**.
6. GitHub will show the public website URL after deployment finishes.

The app download is stored at `downloads/problem-slate-macOS.zip`. When releasing an update, replace that file and update the visible version number in `index.html`.
